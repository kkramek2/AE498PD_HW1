# AE498PD_HW1

For this assignment, we are tasked to calculate the minimum orbit intersection distance (MOID) between two heliocentric Keplerian orbits. Keplerian orbital elements for four celestial bodies are provided in this assignment. These bodies include Earth, 99942 Apophis, 2024 YR4, and 3I/ATLAS. The MOID is calculated and presented in km, AU, and in terms of ($f_1$, $f_2$), the true anomaly coordinates on both orbits.
